`@sideseat/sdk` is an OpenTelemetry distribution for AI applications on Node.js. One call configures
tracing, metrics, and logs for a SideSeat project, switches on your framework's telemetry, and attributes every
span to the right session and user.

## Install

<Tabs>
  <TabItem label="npm">
    ```bash
    npm install @sideseat/sdk
    ```
  </TabItem>
  <TabItem label="pnpm">
    ```bash
    pnpm add @sideseat/sdk
    ```
  </TabItem>
</Tabs>

Node.js 20.19 or newer. Start a local server with `npx sideseat`.

## Quick start

```ts
import * as sideseat from "@sideseat/sdk";
import { Agent } from "@strands-agents/sdk";

await sideseat.init({ integrations: ["strands"] });

const agent = new Agent({ model: "global.anthropic.claude-sonnet-5-5" });

await sideseat.session({ sessionId: "conversation-42", userId: "user-7" }, async () => {
  await agent.invoke("Plan a weekend in Lisbon.");
  await agent.invoke("What should I eat there?");
});
```

Call `init` before your framework creates its first span. It points OpenTelemetry at
`http://127.0.0.1:5388` and the `default` project; [configuration](/docs/sdks/typescript/configuration/)
covers everything else.

## Sessions and users

`session()` is a scope, not a span: every span started inside the callback - including the ones your
framework creates - gets `session.id` and `user.id`. `sessionId` is required; `userId` is optional, and
both must be non-empty. A nested scope overrides the outer one until its callback returns. The values
follow the async context and are never sent as W3C baggage, which HTTP instrumentation would forward to
model providers.

## Traces and spans

```ts
await sideseat.trace("plan-trip", { sessionId: "s-1", userId: "u-1" }, async () => {
  const documents = await sideseat.span("retrieve-context", async (span) => {
    span.setAttribute("app.documents", 4);
    return loadDocuments();
  });
  await agent.invoke(`Plan a trip using: ${documents}`);
});
```

`trace()` always starts a root span; `span()` starts a child of the active span. Both resolve to the
callback's result, and record and rethrow its exception.

## Integrations

| Name | Framework | Notes |
| --- | --- | --- |
| `strands` | `@strands-agents/sdk` | Emits through the global tracer provider. |
| `vercel-ai` | `ai` 7 or newer | Registers `@ai-sdk/otel` (install it alongside `ai`). Each call still needs `experimental_telemetry: { isEnabled: true }`. |
| `claude-agent-sdk` | `@anthropic-ai/claude-agent-sdk` | Configures the telemetry of the Claude Code CLI it spawns through environment variables it inherits. They never replace a value you set, and are removed at shutdown. If you pass `options.env`, spread `process.env` into it. |

Without `integrations`, the installed framework is detected. Pass `[]` for none. Naming an integration
whose package is not installed rejects with `IntegrationError`; a detected one that cannot install is
skipped with a warning.

## Shutdown

`shutdown()` runs before the process exits and on `SIGINT` and `SIGTERM`, after which the signal ends the
process as it would have without SideSeat. In a serverless handler, `await sideseat.flush()` before
returning. Both take a timeout in milliseconds (30 seconds by default) and resolve to whether every
span, metric, and log record was exported; export failures never throw. `shutdown()` is idempotent.

## Testing your application

```ts
import { capture } from "@sideseat/sdk/testing";

const spans = await capture({ integrations: [] }, () =>
  sideseat.session({ sessionId: "s-1" }, () => runAgent()),
);
```

`capture` initializes SideSeat without export, runs the callback, shuts down, and resolves to the
finished spans. It resets OpenTelemetry's global registrations, so use it only in tests. To write spans
to a file instead, `JsonlSpanExporter` from `@sideseat/sdk/exporters` writes one JSON object per span.
