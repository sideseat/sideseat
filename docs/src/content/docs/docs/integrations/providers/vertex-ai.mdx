The `vertex-ai` integration instruments the `google-genai` client in its Google Cloud mode through
Logfire's Google Gen AI instrumentation. Every model call becomes a span with the model, token usage,
cost, and the full conversation, including automatic function calls.

## Install

```bash
pip install "sideseat[vertex-ai]" google-genai
gcloud auth application-default login
```

The client uses [Application Default Credentials](https://cloud.google.com/docs/authentication/provide-credentials-adc);
in production, prefer the workload's attached service account.

## Quick start

```python
import sideseat
from google import genai

sideseat.init(integrations=["vertex-ai"])

vertex = genai.Client(enterprise=True, project="your-project", location="us-central1")
response = vertex.models.generate_content(
    model="gemini-2.5-flash",
    contents="What is the speed of light?",
)
print(response.text)
```

The Developer API and Vertex AI share one package and instrumentation, so package detection cannot
tell them apart: name `vertex-ai` in `integrations`.

The client can also read its settings from the environment:

```bash
export GOOGLE_GENAI_USE_ENTERPRISE=true
export GOOGLE_CLOUD_PROJECT=your-project
export GOOGLE_CLOUD_LOCATION=us-central1
```

## Traces and sessions

```python
with sideseat.session("conversation-42", user_id="user-7"):
    with sideseat.trace("plan-trip"):
        chat = vertex.chats.create(model="gemini-2.5-flash")
        chat.send_message("Plan a weekend in Lisbon.")
        for chunk in chat.send_message_stream("What should I eat there?"):
            print(chunk.text or "", end="", flush=True)

    with sideseat.trace("follow-up"):
        vertex.models.generate_content(
            model="gemini-2.5-flash",
            contents="Which Lisbon museums open on Mondays?",
        )
```

The chat API re-sends earlier turns with each message; SideSeat shows the conversation once, in
order, and groups both traces into one session.

## Tool use

Pass Python functions as tools. The client calls them and returns their results to the model:

```python
from google.genai import types


def get_weather(location: str) -> str:
    """Get the current weather for a city."""
    return f"Sunny, 22°C in {location}."


response = vertex.models.generate_content(
    model="gemini-2.5-flash",
    contents="What's the weather in London?",
    config=types.GenerateContentConfig(tools=[get_weather]),
)
print(response.text)
```

SideSeat shows the tool definition, the call, its result, and the final answer in that order.

## Without the SideSeat SDK

```bash
pip install google-genai "logfire[google-genai]" opentelemetry-exporter-otlp-proto-http
export OTEL_INSTRUMENTATION_GENAI_CAPTURE_MESSAGE_CONTENT=true
```

```python
import logfire
from opentelemetry.exporter.otlp.proto.http.trace_exporter import OTLPSpanExporter
from opentelemetry.sdk.trace.export import BatchSpanProcessor

logfire.configure(
    service_name="my-app",
    send_to_logfire=False,
    console=False,
    additional_span_processors=[
        BatchSpanProcessor(OTLPSpanExporter(endpoint="http://127.0.0.1:5388/otel/default/v1/traces"))
    ],
)
logfire.instrument_google_genai()
```

Create `genai.Client(enterprise=True, ...)` after instrumenting. SideSeat identifies Vertex AI
telemetry by the `opentelemetry.instrumentation.google_genai` scope together with
`gen_ai.provider.name=vertex_ai`.

<Aside type="caution">
Logfire scrubs attributes whose names contain `session`, including `session.id`. Without the SDK,
pass a `logfire.ScrubbingOptions(callback=...)` that keeps `session.id`.
</Aside>

## Known limits

- Use the `google-genai` client. The older `vertexai` Python package is not instrumented.
- Gemini's thoughts are exported as ordinary text parts and appear as assistant text.
