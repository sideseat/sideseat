The `openai` integration instruments the OpenAI Python SDK through Logfire's OpenAI instrumentation.
Responses and Chat Completions calls become spans with the model, token usage, cost, and the full
conversation, including tool calls and their results.

## Install

```bash
pip install "sideseat[openai]" openai
export OPENAI_API_KEY=sk-...
```

## Quick start

```python
import sideseat
from openai import OpenAI

sideseat.init(integrations=["openai"])

client = OpenAI()
response = client.responses.create(
    model="gpt-6.1-sol",
    instructions="Answer in one sentence.",
    input="What is the speed of light?",
)
print(response.output_text)
```

The provider client is never auto-detected, so name `openai` in `integrations`. For Azure, use the
[Azure OpenAI](/docs/integrations/providers/azure/) integration instead.

## Traces and sessions

Without a trace, each call is its own trace. Wrap related calls in `sideseat.trace()` to make them one
trace, and in `sideseat.session()` to group several traces into one conversation:

```python
with sideseat.session("conversation-42", user_id="user-7"):
    with sideseat.trace("plan-trip"):
        messages = [{"role": "user", "content": "Plan a weekend in Lisbon."}]
        reply = client.chat.completions.create(model="gpt-6.1-sol", messages=messages)
        messages += [
            {"role": "assistant", "content": reply.choices[0].message.content},
            {"role": "user", "content": "What should I eat there?"},
        ]
        client.chat.completions.create(model="gpt-6.1-sol", messages=messages)

    with sideseat.trace("follow-up"):
        client.responses.create(model="gpt-6.1-sol", input="Which Lisbon museums open on Mondays?")
```

The session view shows both traces in order. History re-sent on the second call of `plan-trip` is
shown once, not duplicated.

## Streaming

```python
stream = client.chat.completions.create(
    model="gpt-6.1-sol",
    messages=[{"role": "user", "content": "What is the boiling point of water?"}],
    stream=True,
    stream_options={"include_usage": True},
)
for chunk in stream:
    if chunk.choices and chunk.choices[0].delta.content:
        print(chunk.choices[0].delta.content, end="", flush=True)
```

The completed response and its token usage are reconstructed from the stream and recorded in the
request's trace.

## Tool use

```python
import json

tools = [{
    "type": "function",
    "name": "get_weather",
    "description": "Get the current weather for a city.",
    "parameters": {
        "type": "object",
        "properties": {"location": {"type": "string"}},
        "required": ["location"],
    },
}]

response = client.responses.create(
    model="gpt-6.1-sol", input="What's the weather in Paris?", tools=tools
)
outputs = [
    {
        "type": "function_call_output",
        "call_id": item.call_id,
        "output": json.dumps({"location": json.loads(item.arguments)["location"], "sky": "sunny"}),
    }
    for item in response.output
    if item.type == "function_call"
]
final = client.responses.create(
    model="gpt-6.1-sol", previous_response_id=response.id, input=outputs, tools=tools
)
print(final.output_text)
```

Each request is a span. SideSeat links every function result to its call and shows the tool
definitions on the request.

## Images

```python
import base64

with open("photo.jpg", "rb") as file:
    image = base64.b64encode(file.read()).decode()

client.responses.create(
    model="gpt-6.1-sol",
    input=[{
        "role": "user",
        "content": [
            {"type": "input_text", "text": "What's in this image?"},
            {"type": "input_image", "image_url": f"data:image/jpeg;base64,{image}"},
        ],
    }],
)
```

The server moves the image to file storage and shows it inline in the conversation.

## Without the SideSeat SDK

```bash
pip install openai logfire opentelemetry-exporter-otlp-proto-http
```

```python
import logfire
from opentelemetry.exporter.otlp.proto.http.trace_exporter import OTLPSpanExporter
from opentelemetry.sdk.trace.export import BatchSpanProcessor

logfire.configure(
    service_name="my-app",
    send_to_logfire=False,
    console=False,
    additional_span_processors=[
        BatchSpanProcessor(OTLPSpanExporter(endpoint="http://127.0.0.1:5388/otel/default/v1/traces"))
    ],
)
logfire.instrument_openai()
```

<Aside type="caution">
Logfire scrubs attributes whose names contain `session`, including `session.id`. Without the SDK,
pass a `logfire.ScrubbingOptions(callback=...)` that keeps `session.id`.
</Aside>

## Known limits

- A streamed response is logged by Logfire after its request span ends. The SDK moves that log into
  the request's trace; without the SDK, a streamed response that has no parent span can arrive as a
  separate trace. Wrap streaming calls in a trace to keep them together.
- `previous_response_id` keeps history on OpenAI's servers, so SideSeat shows only what each request
  sent and received.
