The `anthropic` integration instruments the Anthropic Python SDK through Logfire's Anthropic
instrumentation. Every Messages API call becomes a span with the model, token usage, cost, and the
full conversation: system prompt, messages, thinking, tool calls, and tool results.

## Install

```bash
pip install "sideseat[anthropic]" anthropic
export ANTHROPIC_API_KEY=sk-ant-...
```

## Quick start

```python
import anthropic
import sideseat

sideseat.init(integrations=["anthropic"])

claude = anthropic.Anthropic()
message = claude.messages.create(
    model="claude-sonnet-5-5",
    system="Answer in one sentence.",
    max_tokens=1024,
    messages=[{"role": "user", "content": "What is the speed of light?"}],
)
print(message.content[0].text)
```

The provider client is never auto-detected, so name `anthropic` in `integrations`.

## Traces and sessions

Without a trace, each call is its own trace. Wrap related calls in `sideseat.trace()` to make them one
trace, and in `sideseat.session()` to group several traces into one conversation:

```python
with sideseat.session("conversation-42", user_id="user-7"):
    with sideseat.trace("plan-trip"):
        messages = [{"role": "user", "content": "Plan a weekend in Lisbon."}]
        reply = claude.messages.create(
            model="claude-sonnet-5-5", max_tokens=1024, messages=messages
        )
        messages += [
            {"role": "assistant", "content": reply.content},
            {"role": "user", "content": "What should I eat there?"},
        ]
        claude.messages.create(model="claude-sonnet-5-5", max_tokens=1024, messages=messages)

    with sideseat.trace("follow-up"):
        claude.messages.create(
            model="claude-sonnet-5-5",
            max_tokens=1024,
            messages=[{"role": "user", "content": "Which Lisbon museums open on Mondays?"}],
        )
```

The session view shows both traces in order. History re-sent on the second call of `plan-trip` is
shown once, not duplicated.

## Streaming

```python
with claude.messages.stream(
    model="claude-sonnet-5-5",
    max_tokens=1024,
    messages=[{"role": "user", "content": "What is the boiling point of water?"}],
) as stream:
    for text in stream.text_stream:
        print(text, end="", flush=True)
```

The streamed response and its token usage are recorded on the request's span.

## Thinking

```python
message = claude.messages.create(
    model="claude-sonnet-5-5",
    max_tokens=16000,
    thinking={"type": "adaptive", "display": "summarized"},
    messages=[{"role": "user", "content": "Is 1,000,003 prime?"}],
)
```

Current Claude models decide how much to think and omit the reasoning text unless `display` is
`summarized`. The summary appears as a thinking block before the answer. Without it, the block appears as
reasoning whose text was omitted, marked signed.

## Tool use

```python
tools = [{
    "name": "get_weather",
    "description": "Get the current weather for a city.",
    "input_schema": {
        "type": "object",
        "properties": {"location": {"type": "string"}},
        "required": ["location"],
    },
}]
messages = [{"role": "user", "content": "What's the weather in Paris?"}]

while True:
    reply = claude.messages.create(
        model="claude-sonnet-5-5", max_tokens=1024, tools=tools, messages=messages
    )
    messages.append({"role": "assistant", "content": reply.content})
    if reply.stop_reason != "tool_use":
        break
    messages.append({
        "role": "user",
        "content": [
            {"type": "tool_result", "tool_use_id": block.id, "content": "Sunny, 22°C"}
            for block in reply.content
            if block.type == "tool_use"
        ],
    })
```

Each round is a span. SideSeat links every tool result to its call and shows the tool definitions
on the request.

## Images and documents

```python
import base64

def encoded(path: str) -> str:
    with open(path, "rb") as file:
        return base64.b64encode(file.read()).decode()

claude.messages.create(
    model="claude-sonnet-5-5",
    max_tokens=1024,
    messages=[{
        "role": "user",
        "content": [
            {"type": "text", "text": "Summarize the photo and the PDF."},
            {"type": "image", "source": {"type": "base64", "media_type": "image/jpeg", "data": encoded("photo.jpg")}},
            {"type": "document", "source": {"type": "base64", "media_type": "application/pdf", "data": encoded("report.pdf")}},
        ],
    }],
)
```

The server moves the attachments to file storage and shows them inline in the conversation.

## Without the SideSeat SDK

Configure Logfire without its cloud exporter and attach an OTLP exporter pointed at SideSeat:

```bash
pip install anthropic logfire opentelemetry-exporter-otlp-proto-http
```

```python
import logfire
from opentelemetry.exporter.otlp.proto.http.trace_exporter import OTLPSpanExporter
from opentelemetry.sdk.trace.export import BatchSpanProcessor

logfire.configure(
    service_name="my-app",
    send_to_logfire=False,
    console=False,
    additional_span_processors=[
        BatchSpanProcessor(OTLPSpanExporter(endpoint="http://127.0.0.1:5388/otel/default/v1/traces"))
    ],
)
logfire.instrument_anthropic()
```

<Aside type="caution">
Logfire scrubs attributes whose names contain `session`, including `session.id`. Without the SDK,
pass a `logfire.ScrubbingOptions(callback=...)` that keeps `session.id`, or every conversation lands
in one session.
</Aside>
