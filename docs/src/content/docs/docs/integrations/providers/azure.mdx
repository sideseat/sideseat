Azure OpenAI's v1 API uses the standard OpenAI client with an Azure resource URL. The `azure-openai`
integration instruments that client with OpenInference, so Azure calls keep their provider identity
and record messages, tools, token usage, and cost.

## Install

```bash
pip install "sideseat[azure-openai]" openai
export AZURE_OPENAI_API_KEY=...
```

Azure and public OpenAI share the `openai` package, so name `azure-openai` explicitly; it is never
auto-detected.

## Quick start

```python
import os

import sideseat
from openai import OpenAI

sideseat.init(integrations=["azure-openai"])

azure = OpenAI(
    api_key=os.environ["AZURE_OPENAI_API_KEY"],
    base_url="https://YOUR-RESOURCE.openai.azure.com/openai/v1/",
)
response = azure.chat.completions.create(
    model="YOUR-DEPLOYMENT",
    messages=[{"role": "user", "content": "What is the speed of light?"}],
)
print(response.choices[0].message.content)
```

<Aside type="tip">
`model` is the Azure deployment name. It does not have to match the underlying model's catalog name.
</Aside>

## Traces and sessions

```python
with sideseat.session("conversation-42", user_id="user-7"):
    with sideseat.trace("plan-trip"):
        messages = [{"role": "user", "content": "Plan a weekend in Lisbon."}]
        reply = azure.chat.completions.create(model="YOUR-DEPLOYMENT", messages=messages)
        messages += [
            {"role": "assistant", "content": reply.choices[0].message.content},
            {"role": "user", "content": "What should I eat there?"},
        ]
        azure.chat.completions.create(model="YOUR-DEPLOYMENT", messages=messages)

    with sideseat.trace("follow-up"):
        azure.chat.completions.create(
            model="YOUR-DEPLOYMENT",
            messages=[{"role": "user", "content": "Which Lisbon museums open on Mondays?"}],
        )
```

The session view shows both traces in order, and history re-sent on a later call is shown once.

## Streaming

```python
stream = azure.chat.completions.create(
    model="YOUR-DEPLOYMENT",
    messages=[{"role": "user", "content": "Explain quantum computing briefly."}],
    stream=True,
    stream_options={"include_usage": True},
)
for chunk in stream:
    if chunk.choices and chunk.choices[0].delta.content:
        print(chunk.choices[0].delta.content, end="", flush=True)
```

The completed response and usage are reconstructed from the stream rather than shown chunk by chunk.

## Tool use

```python
import json

tools = [{
    "type": "function",
    "function": {
        "name": "get_weather",
        "description": "Get the current weather for a city.",
        "parameters": {
            "type": "object",
            "properties": {"location": {"type": "string"}},
            "required": ["location"],
        },
    },
}]
messages = [{"role": "user", "content": "What is the weather in Paris?"}]

reply = azure.chat.completions.create(model="YOUR-DEPLOYMENT", messages=messages, tools=tools)
assistant = reply.choices[0].message
messages.append(assistant.model_dump(exclude_none=True))
for call in assistant.tool_calls or []:
    location = json.loads(call.function.arguments)["location"]
    messages.append({"role": "tool", "tool_call_id": call.id, "content": f"Sunny, 22°C in {location}."})

final = azure.chat.completions.create(model="YOUR-DEPLOYMENT", messages=messages, tools=tools)
print(final.choices[0].message.content)
```

SideSeat orders each tool result after its call and shows it once, even though the final request
re-sends the whole history.

## Microsoft Entra ID

Pass a token provider as the client's `api_key`:

```python
from azure.identity import DefaultAzureCredential, get_bearer_token_provider
from openai import OpenAI

token_provider = get_bearer_token_provider(
    DefaultAzureCredential(), "https://cognitiveservices.azure.com/.default"
)
azure = OpenAI(
    api_key=token_provider,
    base_url="https://YOUR-RESOURCE.openai.azure.com/openai/v1/",
)
```

## The `AzureOpenAI` client

The deployment-based client is traced the same way, including its Responses API calls:

```python
import os

from openai import AzureOpenAI

azure = AzureOpenAI(
    azure_endpoint="https://YOUR-RESOURCE.openai.azure.com",
    api_version="2025-04-01-preview",
    api_key=os.environ["AZURE_OPENAI_API_KEY"],
)
azure.chat.completions.create(
    model="YOUR-DEPLOYMENT",
    messages=[{"role": "user", "content": "What is the speed of light?"}],
)
```

## Images and documents

OpenInference replaces a base64 image longer than 32,000 characters with `__REDACTED__`. Set
`OPENINFERENCE_BASE64_IMAGE_MAX_LENGTH` to a larger value before the instrumentor starts to keep
larger images. PDFs sent as `file` parts are shown as documents.

## Without the SideSeat SDK

```bash
pip install openai openinference-instrumentation-openai opentelemetry-sdk opentelemetry-exporter-otlp-proto-http
```

```python
from openinference.instrumentation.openai import OpenAIInstrumentor
from opentelemetry import trace
from opentelemetry.exporter.otlp.proto.http.trace_exporter import OTLPSpanExporter
from opentelemetry.sdk.trace import TracerProvider
from opentelemetry.sdk.trace.export import BatchSpanProcessor

provider = TracerProvider()
provider.add_span_processor(
    BatchSpanProcessor(OTLPSpanExporter(endpoint="http://127.0.0.1:5388/otel/default/v1/traces"))
)
trace.set_tracer_provider(provider)
OpenAIInstrumentor().instrument(tracer_provider=provider)
```

SideSeat recognizes Azure from the instrumentor's `llm.provider=azure` attribute.
