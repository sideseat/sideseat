Azure OpenAI's v1 API uses the standard OpenAI client with an Azure resource URL. SideSeat
instruments that client with OpenInference so Azure calls keep their provider identity while
exposing messages, tools, token usage, traces, and sessions.

## Prerequisites

- SideSeat running locally (`sideseat`)
- Python SDK installed with `pip install "sideseat[azure-openai]"`
- An Azure OpenAI resource, API key, and deployed model

Azure and public OpenAI share the `openai` Python package. Pass
`Frameworks.AzureOpenAI` explicitly; this provider is not auto-detected.

## Quick start

```python
import os

from openai import OpenAI
from sideseat import Frameworks, SideSeat

SideSeat(framework=Frameworks.AzureOpenAI)

azure = OpenAI(
    api_key=os.environ["AZURE_OPENAI_API_KEY"],
    base_url="https://YOUR-RESOURCE.openai.azure.com/openai/v1/",
)

response = azure.chat.completions.create(
    model="YOUR-DEPLOYMENT",
    messages=[
        {"role": "system", "content": "Answer in one sentence."},
        {"role": "user", "content": "What is the speed of light?"},
    ],
)
print(response.choices[0].message.content)
```

<Aside type="tip">
`model` is the Azure deployment name. It does not have to equal the underlying model's
catalog name.
</Aside>

## Traces and sessions

Use `client.trace()` to parent related model calls. Give independent traces the same
`session_id` to make them one session without merging their trace identities:

```python
import os

from openai import OpenAI
from sideseat import Frameworks, SideSeat

client = SideSeat(framework=Frameworks.AzureOpenAI)
azure = OpenAI(
    api_key=os.environ["AZURE_OPENAI_API_KEY"],
    base_url="https://YOUR-RESOURCE.openai.azure.com/openai/v1/",
)

session_id = "sess-abc"

with client.trace("research", session_id=session_id, user_id="user-123"):
    messages = [
        {"role": "system", "content": "Be concise."},
        {"role": "user", "content": "What is the speed of light?"},
    ]
    first = azure.chat.completions.create(
        model="YOUR-DEPLOYMENT",
        messages=messages,
    )
    messages.append(
        {"role": "assistant", "content": first.choices[0].message.content}
    )
    messages.append(
        {"role": "user", "content": "What is the boiling point of water?"}
    )
    azure.chat.completions.create(
        model="YOUR-DEPLOYMENT",
        messages=messages,
    )

with client.trace("weather", session_id=session_id, user_id="user-123"):
    azure.chat.completions.create(
        model="YOUR-DEPLOYMENT",
        messages=[{"role": "user", "content": "What is the weather in Paris?"}],
    )
```

The first trace reconstructs the retained multi-turn history. The session view returns both
traces in order and does not duplicate the history re-sent to the second model call.

## Streaming

```python
stream = azure.chat.completions.create(
    model="YOUR-DEPLOYMENT",
    messages=[{"role": "user", "content": "Explain quantum computing briefly."}],
    stream=True,
    stream_options={"include_usage": True},
)

for chunk in stream:
    if chunk.choices and chunk.choices[0].delta.content:
        print(chunk.choices[0].delta.content, end="", flush=True)
```

The completed response and usage are reconstructed from the stream rather than presenting
each chunk as a separate message.

## Tool use

```python
import json

tools = [
    {
        "type": "function",
        "function": {
            "name": "get_weather",
            "description": "Get deterministic weather for a city.",
            "parameters": {
                "type": "object",
                "properties": {"location": {"type": "string"}},
                "required": ["location"],
            },
        },
    }
]
messages = [
    {"role": "system", "content": "Use tools when available."},
    {"role": "user", "content": "What is the weather in Paris?"},
]

request = azure.chat.completions.create(
    model="YOUR-DEPLOYMENT",
    messages=messages,
    tools=tools,
)
assistant = request.choices[0].message
call = assistant.tool_calls[0]
arguments = json.loads(call.function.arguments)

messages.extend(
    [
        assistant.model_dump(exclude_none=True),
        {
            "role": "tool",
            "tool_call_id": call.id,
            "name": call.function.name,
            "content": f"Sunny and 22°C in {arguments['location']}.",
        },
    ]
)
final = azure.chat.completions.create(
    model="YOUR-DEPLOYMENT",
    messages=messages,
    tools=tools,
)
print(final.choices[0].message.content)
```

SideSeat keeps the tool definition, call ID, arguments, result, and final answer. The tool
result is ordered after its matching call and appears once even though the final request
re-sends the full history.

## Without the SideSeat SDK

Install the same instrumentor directly and bind it to your OpenTelemetry provider:

```bash
pip install openai openinference-instrumentation-openai
```

```python
from openinference.instrumentation.openai import OpenAIInstrumentor

OpenAIInstrumentor().instrument(tracer_provider=provider)
```

Configure an OTLP exporter on `provider` and set the normal SideSeat resource attributes,
including `sideseat.framework=azure-openai`, when you need explicit framework tagging.
Azure provider detection also uses the OpenInference `llm.provider=azure` and
`llm.system=openai` attributes emitted by the instrumentor.

## Authentication

For an API key:

```bash
export AZURE_OPENAI_API_KEY=your-api-key
```

For Microsoft Entra ID, pass a token provider as the OpenAI client's `api_key`:

```python
from azure.identity import DefaultAzureCredential, get_bearer_token_provider
from openai import OpenAI

token_provider = get_bearer_token_provider(
    DefaultAzureCredential(),
    "https://cognitiveservices.azure.com/.default",
)
azure = OpenAI(
    api_key=token_provider,
    base_url="https://YOUR-RESOURCE.openai.azure.com/openai/v1/",
)
```

## Verified contract

The checked-in native and SideSeat fixtures use OpenAI 3.22.1,
OpenInference OpenAI 0.1.62, OpenTelemetry Python 1.45.0, and CPython 3.14.7. They verify:

- non-streaming and streaming Chat Completions;
- retained multi-turn history without duplicates;
- a complete tool-call, result, and final-answer roundtrip;
- two traces sharing one session;
- identical span, trace, session, and project-feed answers with and without the SDK.

Reproduce them without Azure credentials:

```bash
scripts/message-fixtures/fake-openai.py --port 5401
# In another shell:
CAPTURE_MODEL=gpt-5-nano-2025-08-07 \
  scripts/message-fixtures/capture.sh azure-openai canonical both
```
