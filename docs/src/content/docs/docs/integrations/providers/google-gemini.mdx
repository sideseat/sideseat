The `google-genai` integration instruments the [Google Gen AI SDK](https://github.com/googleapis/python-genai)
through Logfire's Google Gen AI instrumentation. Every model call becomes a span with the model,
token usage, cost, and the full conversation, including automatic function calls.

The same SDK serves the Gemini Developer API and Google Cloud. For Google Cloud, see
[Google Vertex AI](/docs/integrations/providers/vertex-ai/).

## Install

```bash
pip install "sideseat[google-genai]" google-genai
export GEMINI_API_KEY=...
```

## Quick start

```python
import sideseat
from google import genai

sideseat.init(integrations=["google-genai"])

gemini = genai.Client()
response = gemini.models.generate_content(
    model="gemini-2.5-flash",
    contents="What is the speed of light?",
)
print(response.text)
```

The provider client is never auto-detected, so name `google-genai` in `integrations`.

## Traces and sessions

Without a trace, each call is its own trace. Wrap related calls in `sideseat.trace()` to make them one
trace, and in `sideseat.session()` to group several traces into one conversation:

```python
with sideseat.session("conversation-42", user_id="user-7"):
    with sideseat.trace("plan-trip"):
        chat = gemini.chats.create(model="gemini-2.5-flash")
        chat.send_message("Plan a weekend in Lisbon.")
        chat.send_message("What should I eat there?")

    with sideseat.trace("follow-up"):
        gemini.models.generate_content(
            model="gemini-2.5-flash",
            contents="Which Lisbon museums open on Mondays?",
        )
```

The chat API re-sends earlier turns with each message; SideSeat shows them once, in order.

## Streaming

```python
for chunk in gemini.models.generate_content_stream(
    model="gemini-2.5-flash",
    contents="What is the boiling point of water?",
):
    print(chunk.text or "", end="", flush=True)
```

## Tool use

Pass Python functions as tools. The client calls them and returns their results to the model:

```python
from google.genai import types


def get_weather(location: str) -> str:
    """Get the current weather for a city."""
    return f"Sunny, 22°C in {location}"


response = gemini.models.generate_content(
    model="gemini-2.5-flash",
    contents="What's the weather in Paris?",
    config=types.GenerateContentConfig(tools=[get_weather]),
)
print(response.text)
```

SideSeat shows the tool definition, the call, its result, and the final answer in that order.

## Thinking

```python
response = gemini.models.generate_content(
    model="gemini-2.5-flash",
    contents="Is 1,000,003 prime?",
    config=types.GenerateContentConfig(
        thinking_config=types.ThinkingConfig(include_thoughts=True)
    ),
)
```

Gemini returns thought summaries only when `include_thoughts` is set.

## Without the SideSeat SDK

```bash
pip install google-genai "logfire[google-genai]" opentelemetry-exporter-otlp-proto-http
export OTEL_INSTRUMENTATION_GENAI_CAPTURE_MESSAGE_CONTENT=true
```

```python
import logfire
from opentelemetry.exporter.otlp.proto.http.trace_exporter import OTLPSpanExporter
from opentelemetry.sdk.trace.export import BatchSpanProcessor

logfire.configure(
    service_name="my-app",
    send_to_logfire=False,
    console=False,
    additional_span_processors=[
        BatchSpanProcessor(OTLPSpanExporter(endpoint="http://127.0.0.1:5388/otel/default/v1/traces"))
    ],
)
logfire.instrument_google_genai()
```

<Aside type="caution">
Logfire scrubs attributes whose names contain `session`, including `session.id`. Without the SDK,
pass a `logfire.ScrubbingOptions(callback=...)` that keeps `session.id`.
</Aside>

## Known limits

- The instrumentation exports Gemini's thoughts as ordinary text parts, so a thought summary appears
  as assistant text rather than as a thinking block.
- The Developer API and Google Cloud share one package and instrumentation; select the matching
  integration by name. A Google Cloud client is created with `genai.Client(enterprise=True, ...)`.
- The captured fixtures use Google GenAI 2.28.0 with Logfire 5.1.1.
