The `bedrock` integration instruments boto3 Bedrock Runtime clients. Converse, ConverseStream,
InvokeModel, and InvokeModelWithResponseStream calls become spans with the model, token usage, cost,
and the full conversation, including reasoning, tool calls, and tool results.

## Install

```bash
pip install "sideseat[bedrock]" boto3
```

The `bedrock` extra installs `wrapt`, which the instrumentation needs. Credentials come from the
standard AWS chain (`AWS_PROFILE`, environment variables, or an attached role).

## Quick start

```python
import boto3
import sideseat

sideseat.init(integrations=["bedrock"])

bedrock = boto3.client("bedrock-runtime", region_name="us-east-1")
response = bedrock.converse(
    modelId="global.anthropic.claude-sonnet-5-5",
    system=[{"text": "Answer in one sentence."}],
    messages=[{"role": "user", "content": [{"text": "What is the speed of light?"}]}],
)
print(response["output"]["message"]["content"][0]["text"])
```

<Aside>
Create boto3 clients after `sideseat.init`: the integration instruments clients as they are created.
The provider is never auto-detected, so name `bedrock` in `integrations`.
</Aside>

## Traces and sessions

Without a trace, each call is its own trace. Wrap related calls in `sideseat.trace()` to make them one
trace, and in `sideseat.session()` to group several traces into one conversation:

```python
model_id = "global.anthropic.claude-sonnet-5-5"

with sideseat.session("conversation-42", user_id="user-7"):
    with sideseat.trace("plan-trip"):
        messages = [{"role": "user", "content": [{"text": "Plan a weekend in Lisbon."}]}]
        response = bedrock.converse(modelId=model_id, messages=messages)
        messages += [
            response["output"]["message"],
            {"role": "user", "content": [{"text": "What should I eat there?"}]},
        ]
        bedrock.converse(modelId=model_id, messages=messages)

    with sideseat.trace("follow-up"):
        bedrock.converse(
            modelId=model_id,
            messages=[{"role": "user", "content": [{"text": "Which Lisbon museums open on Mondays?"}]}],
        )
```

The session view shows both traces in order. History re-sent on the second call of `plan-trip` is
shown once, not duplicated.

## Streaming

```python
response = bedrock.converse_stream(
    modelId="global.anthropic.claude-sonnet-5-5",
    messages=[{"role": "user", "content": [{"text": "What is the boiling point of water?"}]}],
)
for event in response["stream"]:
    if "contentBlockDelta" in event:
        print(event["contentBlockDelta"]["delta"].get("text", ""), end="", flush=True)
```

The span ends when the stream is consumed and carries the token usage from its metadata event.

## Thinking

```python
response = bedrock.converse(
    modelId="global.anthropic.claude-sonnet-5-5",
    messages=[{"role": "user", "content": [{"text": "Is 1,000,003 prime?"}]}],
    inferenceConfig={"maxTokens": 16000},
    additionalModelRequestFields={"thinking": {"type": "adaptive", "display": "summarized"}},
)
```

Current Claude models decide how much to think and omit the reasoning text unless `display` is
`summarized`. The summary appears as a thinking block before the answer.

## Tool use

```python
model_id = "global.anthropic.claude-sonnet-5-5"
tool_config = {
    "tools": [{
        "toolSpec": {
            "name": "get_weather",
            "description": "Get the current weather for a city.",
            "inputSchema": {"json": {
                "type": "object",
                "properties": {"location": {"type": "string"}},
                "required": ["location"],
            }},
        }
    }]
}
messages = [{"role": "user", "content": [{"text": "What's the weather in Paris?"}]}]

while True:
    response = bedrock.converse(modelId=model_id, messages=messages, toolConfig=tool_config)
    message = response["output"]["message"]
    messages.append(message)
    if response["stopReason"] != "tool_use":
        break
    messages.append({
        "role": "user",
        "content": [
            {"toolResult": {"toolUseId": block["toolUse"]["toolUseId"], "content": [{"text": "Sunny, 22°C"}]}}
            for block in message["content"]
            if "toolUse" in block
        ],
    })
```

Each round is a span. SideSeat links every tool result to its call and shows the tool definitions
on the request.

## InvokeModel

```python
import json

response = bedrock.invoke_model(
    modelId="global.anthropic.claude-sonnet-5-5",
    body=json.dumps({
        "anthropic_version": "bedrock-2023-05-31",
        "max_tokens": 1024,
        "messages": [{"role": "user", "content": "What is the speed of light?"}],
    }),
)
print(json.loads(response["body"].read())["content"][0]["text"])
```

InvokeModel bodies are model-specific; SideSeat reads the Claude Messages format. Use Converse for
other Bedrock models.

## Without the SideSeat SDK

OpenTelemetry's botocore instrumentation records Bedrock calls as spans and their messages as GenAI
log events, so export logs as well as traces:

```bash
pip install boto3 opentelemetry-sdk opentelemetry-exporter-otlp-proto-http opentelemetry-instrumentation-botocore
export OTEL_INSTRUMENTATION_GENAI_CAPTURE_MESSAGE_CONTENT=true
```

```python
from opentelemetry import trace
from opentelemetry._logs import set_logger_provider
from opentelemetry.exporter.otlp.proto.http._log_exporter import OTLPLogExporter
from opentelemetry.exporter.otlp.proto.http.trace_exporter import OTLPSpanExporter
from opentelemetry.instrumentation.botocore import BotocoreInstrumentor
from opentelemetry.sdk._logs import LoggerProvider
from opentelemetry.sdk._logs.export import BatchLogRecordProcessor
from opentelemetry.sdk.trace import TracerProvider
from opentelemetry.sdk.trace.export import BatchSpanProcessor

base = "http://127.0.0.1:5388/otel/default"
provider = TracerProvider()
provider.add_span_processor(BatchSpanProcessor(OTLPSpanExporter(endpoint=f"{base}/v1/traces")))
trace.set_tracer_provider(provider)
logs = LoggerProvider()
logs.add_log_record_processor(BatchLogRecordProcessor(OTLPLogExporter(endpoint=f"{base}/v1/logs")))
set_logger_provider(logs)

BotocoreInstrumentor().instrument(tracer_provider=provider, logger_provider=logs)
```
