[Strands Agents](https://strandsagents.com) is AWS's agent framework. It emits OpenTelemetry GenAI spans
itself; SideSeat points them at your project and keeps images and documents in the telemetry.

## Install

<Tabs>
  <TabItem label="pip">
    ```bash
    pip install strands-agents sideseat
    ```
  </TabItem>
  <TabItem label="uv">
    ```bash
    uv add strands-agents sideseat
    ```
  </TabItem>
</Tabs>

Start a local server with `npx sideseat`. The default model runs on Amazon Bedrock, so configure AWS
credentials and a region.

## Quick start

```python
import sideseat
from strands import Agent, tool

sideseat.init(integrations=["strands"])


@tool
def get_weather(city: str) -> str:
    """Get the weather for a city."""
    return f"Sunny in {city}, 22°C"


agent = Agent(model="global.anthropic.claude-sonnet-5-5", tools=[get_weather])

with sideseat.session("conversation-42", user_id="user-7"):
    agent("What's the weather in Lisbon?")
    agent("And what should I pack?")
```

## Without the SDK

Strands configures OpenTelemetry itself when its `otel` extra is installed:

```bash
pip install "strands-agents[otel]"
export OTEL_EXPORTER_OTLP_ENDPOINT=http://localhost:5388/otel/default
```

```python
from strands import Agent
from strands.telemetry import StrandsTelemetry

StrandsTelemetry().setup_otlp_exporter()

agent = Agent(
    model="global.anthropic.claude-sonnet-5-5",
    trace_attributes={"session.id": "conversation-42", "user.id": "user-7"},
)
agent("What's the weather in Lisbon?")
```

## What you see in SideSeat

- One trace per agent invocation, with a span for each event-loop cycle.
- A span per model call with the model, token counts, and cost.
- A span per tool call with its arguments and result.
- The conversation, including images and documents, in the Messages tab.
- Turns that share a `session.id` grouped into one session.

## Known limits

- Without the SDK, Strands replaces image and document bytes with a placeholder before exporting
  them, so attachments do not appear. The `strands` integration exports them as base64.
