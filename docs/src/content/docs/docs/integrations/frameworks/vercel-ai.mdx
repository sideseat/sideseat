The [Vercel AI SDK](https://ai-sdk.dev/) emits no OpenTelemetry on its own. From AI SDK 7 it hands
telemetry to registered integrations, and `@ai-sdk/otel` is the one that turns it into OpenTelemetry
spans. The `vercel-ai` integration registers it on SideSeat's tracer provider.

## Install

```bash
npm install @sideseat/sdk ai @ai-sdk/otel @ai-sdk/amazon-bedrock zod
```

Node.js 20.19 or newer and `ai` 7 or newer. Start a local server with `npx sideseat`. The examples use
Amazon Bedrock; any [AI SDK provider](https://ai-sdk.dev/providers/ai-sdk-providers) works the same way.

## Quick start

```ts
import * as sideseat from "@sideseat/sdk";
import { bedrock } from "@ai-sdk/amazon-bedrock";
import { generateText, isStepCount, tool } from "ai";
import { z } from "zod";

await sideseat.init({ integrations: ["vercel-ai"] });

const getWeather = tool({
  description: "Get the weather for a city.",
  inputSchema: z.object({ city: z.string() }),
  execute: async ({ city }) => `Sunny in ${city}, 22°C`,
});

await sideseat.session({ sessionId: "conversation-42", userId: "user-7" }, async () => {
  const { text } = await generateText({
    model: bedrock("global.anthropic.claude-sonnet-5-5"),
    prompt: "What's the weather in Lisbon?",
    tools: { getWeather },
    stopWhen: isStepCount(5),
  });
  console.log(text);
});
```

`streamText` is traced the same way. Telemetry is on for every call once the integration is registered;
pass `telemetry: { isEnabled: false }` to opt a call out, or `telemetry: { functionId: "trip-planner" }`
to name it.

<Aside>
Await `init` before the first model call: the integration is registered during initialization, and a
call made earlier is not traced.
</Aside>

## Without the SDK

```bash
npm install ai @ai-sdk/otel @ai-sdk/amazon-bedrock @opentelemetry/sdk-trace-node @opentelemetry/sdk-trace-base @opentelemetry/exporter-trace-otlp-http
export OTEL_EXPORTER_OTLP_ENDPOINT=http://localhost:5388/otel/default
```

```ts
import { bedrock } from "@ai-sdk/amazon-bedrock";
import { OpenTelemetry } from "@ai-sdk/otel";
import { OTLPTraceExporter } from "@opentelemetry/exporter-trace-otlp-http";
import { BatchSpanProcessor } from "@opentelemetry/sdk-trace-base";
import { NodeTracerProvider } from "@opentelemetry/sdk-trace-node";
import { generateText, registerTelemetry } from "ai";

const provider = new NodeTracerProvider({
  spanProcessors: [new BatchSpanProcessor(new OTLPTraceExporter())],
});
provider.register();

// Construct after the provider is registered: the integration captures a tracer.
registerTelemetry(new OpenTelemetry());

const { text } = await generateText({
  model: bedrock("global.anthropic.claude-sonnet-5-5"),
  prompt: "What's the weather in Lisbon?",
});
console.log(text);

await provider.shutdown();
```

## What you see in SideSeat

- One trace per `generateText` or `streamText` call.
- A span per step and per model call, with the model, token counts, and cost.
- A span per tool execution with its input and output.
- The prompt, tool calls, and the final answer in the Messages tab.
