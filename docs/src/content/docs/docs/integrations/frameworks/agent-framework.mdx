[Microsoft Agent Framework](https://github.com/microsoft/agent-framework) has built-in OpenTelemetry
instrumentation. The `agent-framework` integration switches it on and, unless content capture is off,
records prompts, responses, and tool payloads.

## Install

<Tabs>
  <TabItem label="pip">
    ```bash
    pip install agent-framework-core agent-framework-anthropic sideseat
    ```
  </TabItem>
  <TabItem label="uv">
    ```bash
    uv add agent-framework-core agent-framework-anthropic sideseat
    ```
  </TabItem>
</Tabs>

Start a local server with `npx sideseat` and set `ANTHROPIC_API_KEY`. The `agent-framework` meta
package installs every provider connector; `agent-framework-core` plus the one you use is enough.

## Quick start

```python
import asyncio

import sideseat
from agent_framework import Agent
from agent_framework.anthropic import AnthropicClient

sideseat.init(integrations=["agent-framework"])


def get_weather(city: str) -> str:
    """Get the weather for a city."""
    return f"Sunny in {city}, 22°C"


agent = Agent(
    client=AnthropicClient(model="claude-sonnet-5-5"),
    instructions="Answer travel questions. Use get_weather for forecasts.",
    tools=[get_weather],
)


async def main() -> None:
    with sideseat.session("conversation-42", user_id="user-7"):
        result = await agent.run("What's the weather in Lisbon?")
    print(result.text)


asyncio.run(main())
```

For Claude on Amazon Bedrock, use `agent_framework.amazon.AnthropicBedrockClient` with
`model="global.anthropic.claude-sonnet-5-5"`. For OpenAI, install `agent-framework-openai` and use
`agent_framework.openai.OpenAIChatClient(model="gpt-6.1-sol")`.

## .NET

The .NET SDK has an `agent-framework` integration that listens to Agent Framework's activity sources:

```csharp
using SideSeat;

using var sideseat = SideSeatClient.Create(new SideSeatOptions
{
    Integrations = { "agent-framework" },
});
```

See the [.NET SDK](/docs/sdks/dotnet/) for sessions and spans.

## Without the SDK

```bash
pip install agent-framework-core agent-framework-anthropic opentelemetry-sdk opentelemetry-exporter-otlp
export OTEL_EXPORTER_OTLP_ENDPOINT=http://localhost:5388/otel/default
```

```python
from agent_framework.observability import enable_sensitive_telemetry
from opentelemetry import trace
from opentelemetry.exporter.otlp.proto.http.trace_exporter import OTLPSpanExporter
from opentelemetry.sdk.trace import TracerProvider
from opentelemetry.sdk.trace.export import BatchSpanProcessor

provider = TracerProvider()
provider.add_span_processor(BatchSpanProcessor(OTLPSpanExporter()))
trace.set_tracer_provider(provider)
enable_sensitive_telemetry()
```

## What you see in SideSeat

- One trace per `run`, with spans for the agent, each model call, and each tool call.
- Model, token counts, and cost on every model call.
- The conversation, including tool calls, images, and documents, in the Messages tab.

## Known limits

- Without `enable_sensitive_telemetry()` (or the SDK), Agent Framework records spans without message
  content.
