[Google ADK](https://google.github.io/adk-docs/) (Agent Development Kit) emits OpenTelemetry GenAI spans
through the global tracer provider. SideSeat installs that provider and keeps inline images and
documents in the telemetry.

## Install

<Tabs>
  <TabItem label="pip">
    ```bash
    pip install google-adk sideseat
    ```
  </TabItem>
  <TabItem label="uv">
    ```bash
    uv add google-adk sideseat
    ```
  </TabItem>
</Tabs>

Start a local server with `npx sideseat` and set `GOOGLE_API_KEY` for the Gemini API.

## Quick start

```python
import asyncio

import sideseat
from google.adk.agents import Agent
from google.adk.runners import InMemoryRunner
from google.genai import types

sideseat.init(integrations=["google-adk"])


def get_weather(city: str) -> dict:
    """Get the weather for a city."""
    return {"city": city, "forecast": "sunny", "temperature_c": 22}


agent = Agent(
    name="travel_assistant",
    model="gemini-2.5-flash",
    instruction="Answer travel questions. Use get_weather for forecasts.",
    tools=[get_weather],
)


async def main() -> None:
    runner = InMemoryRunner(agent=agent, app_name="travel")
    session = await runner.session_service.create_session(app_name="travel", user_id="user-7")
    message = types.Content(role="user", parts=[types.Part(text="What's the weather in Lisbon?")])

    with sideseat.session(session.id, user_id="user-7"):
        async for event in runner.run_async(
            user_id="user-7", session_id=session.id, new_message=message
        ):
            if event.is_final_response() and event.content and event.content.parts:
                print(event.content.parts[0].text)


asyncio.run(main())
```

## Without the SDK

```bash
pip install google-adk opentelemetry-sdk opentelemetry-exporter-otlp
export OTEL_EXPORTER_OTLP_ENDPOINT=http://localhost:5388/otel/default
```

```python
from opentelemetry import trace
from opentelemetry.exporter.otlp.proto.http.trace_exporter import OTLPSpanExporter
from opentelemetry.sdk.trace import TracerProvider
from opentelemetry.sdk.trace.export import BatchSpanProcessor

provider = TracerProvider()
provider.add_span_processor(BatchSpanProcessor(OTLPSpanExporter()))
trace.set_tracer_provider(provider)
```

## What you see in SideSeat

- One trace per invocation, with spans for the agent, each Gemini call, and each tool call.
- Model, token counts, and cost on every model call.
- The conversation, including tool calls and results, in the Messages tab.

## Known limits

- ADK strips inline image and document bytes from the request it records on spans. The
  `google-adk` integration puts them back; without the SDK, attachments do not appear.
