[AutoGen AgentChat](https://microsoft.github.io/autogen/) builds single agents and multi-agent teams.
SideSeat instruments it with the OpenInference AgentChat instrumentor, which the `autogen` extra
installs. For AG2, the AutoGen fork, see [AG2](/docs/integrations/frameworks/other/#ag2).

## Install

<Tabs>
  <TabItem label="pip">
    ```bash
    pip install autogen-agentchat "autogen-ext[openai]" "sideseat[autogen]"
    ```
  </TabItem>
  <TabItem label="uv">
    ```bash
    uv add autogen-agentchat "autogen-ext[openai]" "sideseat[autogen]"
    ```
  </TabItem>
</Tabs>

Start a local server with `npx sideseat` and set `OPENAI_API_KEY`, or point the client's `base_url`
at any OpenAI-compatible endpoint.

## Quick start

```python
import asyncio

import sideseat
from autogen_agentchat.agents import AssistantAgent
from autogen_ext.models.openai import OpenAIChatCompletionClient

sideseat.init(integrations=["autogen"])


def get_weather(city: str) -> str:
    """Get the weather for a city."""
    return f"Sunny in {city}, 22°C"


async def main() -> None:
    model_client = OpenAIChatCompletionClient(model="gpt-5-mini")
    assistant = AssistantAgent(
        "assistant",
        model_client=model_client,
        tools=[get_weather],
        reflect_on_tool_use=True,
    )
    with sideseat.session("conversation-42", user_id="user-7"):
        result = await assistant.run(task="What's the weather in Lisbon?")
    print(result.messages[-1].to_text())


asyncio.run(main())
```

Teams such as `RoundRobinGroupChat` are traced the same way: each agent's turn is a span under the
team run.

## Without the SDK

```bash
pip install autogen-agentchat "autogen-ext[openai]" openinference-instrumentation-autogen-agentchat opentelemetry-sdk opentelemetry-exporter-otlp
export OTEL_EXPORTER_OTLP_ENDPOINT=http://localhost:5388/otel/default
```

```python
from openinference.instrumentation.autogen_agentchat import AutogenAgentChatInstrumentor
from opentelemetry import trace
from opentelemetry.exporter.otlp.proto.http.trace_exporter import OTLPSpanExporter
from opentelemetry.sdk.trace import TracerProvider
from opentelemetry.sdk.trace.export import BatchSpanProcessor

provider = TracerProvider()
provider.add_span_processor(BatchSpanProcessor(OTLPSpanExporter()))
# Global as well: AgentChat's own GenAI spans go to the global provider.
trace.set_tracer_provider(provider)
AutogenAgentChatInstrumentor().instrument(tracer_provider=provider)
```

## What you see in SideSeat

- One trace per `run`, with spans for the agent or team and each agent's turn.
- A span per model call with the model, token counts, and cost.
- A span per tool execution with its arguments and result.
- The conversation, including tool calls and the reflected answer, in the Messages tab.

## Known limits

- The instrumentor records model requests only from AutoGen's OpenAI clients
  (`OpenAIChatCompletionClient` and its Azure variant). With another model client, such as
  `AnthropicChatCompletionClient`, a trace holds the agent and tool spans but no conversation.

- The OpenInference instrumentor refuses AgentChat versions newer than the one it was released against.
  The SDK skips that check; without the SDK, pass `skip_dep_check=True` to `instrument`.
