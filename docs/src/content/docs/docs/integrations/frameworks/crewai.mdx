[CrewAI](https://www.crewai.com/) orchestrates role-playing agents in crews. SideSeat instruments it
with the OpenInference CrewAI instrumentor, which the `crewai` extra installs.

## Install

<Tabs>
  <TabItem label="pip">
    ```bash
    pip install "crewai[bedrock]" "sideseat[crewai]"
    ```
  </TabItem>
  <TabItem label="uv">
    ```bash
    uv add "crewai[bedrock]" "sideseat[crewai]"
    ```
  </TabItem>
</Tabs>

Start a local server with `npx sideseat`. The model runs on Amazon Bedrock, so configure AWS
credentials.

## Quick start

```python
import sideseat
from crewai import LLM, Agent, Crew, Task
from crewai.tools import tool

sideseat.init(integrations=["crewai"])


@tool("get_weather")
def get_weather(city: str) -> str:
    """Get the weather for a city."""
    return f"Sunny in {city}, 22°C"


llm = LLM(model="bedrock/global.anthropic.claude-sonnet-5-5", region_name="us-east-1")

planner = Agent(
    role="Travel planner",
    goal="Plan short, practical trips",
    backstory="You know the weather everywhere.",
    llm=llm,
    tools=[get_weather],
)
task = Task(
    description="Plan a weekend in Lisbon, taking the weather into account.",
    expected_output="A two-day itinerary.",
    agent=planner,
)

with sideseat.session("conversation-42", user_id="user-7"):
    print(Crew(agents=[planner], tasks=[task]).kickoff())
```

CrewAI does not read `AWS_REGION`, so pass `region_name` to `LLM`.

## Without the SDK

```bash
pip install "crewai[bedrock]" openinference-instrumentation-crewai opentelemetry-sdk opentelemetry-exporter-otlp
export OTEL_EXPORTER_OTLP_ENDPOINT=http://localhost:5388/otel/default
```

```python
from openinference.instrumentation.crewai import CrewAIInstrumentor
from opentelemetry import trace
from opentelemetry.exporter.otlp.proto.http.trace_exporter import OTLPSpanExporter
from opentelemetry.sdk.trace import TracerProvider
from opentelemetry.sdk.trace.export import BatchSpanProcessor

provider = TracerProvider()
provider.add_span_processor(BatchSpanProcessor(OTLPSpanExporter()))
trace.set_tracer_provider(provider)
CrewAIInstrumentor().instrument(tracer_provider=provider)
```

## What you see in SideSeat

- One trace per `kickoff`, with spans for the crew, each task, and each agent's work.
- A span per model call with the model, token counts, and cost.
- A span per tool call with its arguments and result.
- Multi-agent crews, sequential or hierarchical, in one trace.

## Known limits

- CrewAI builds each agent's system prompt from its role, goal, and backstory; that generated prompt is
  what appears as the system message.
- The OpenInference instrumentor refuses CrewAI versions newer than the one it was released against.
  The SDK skips that check; without the SDK, pass `skip_dep_check=True` to `instrument`.
