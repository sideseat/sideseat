The [OpenAI Agents SDK](https://openai.github.io/openai-agents-python/) has its own tracing model.
SideSeat turns it into OpenTelemetry through Logfire's `instrument_openai_agents`, with Logfire
configured to send nothing to Logfire itself. The `openai-agents` extra installs Logfire.

## Install

<Tabs>
  <TabItem label="pip">
    ```bash
    pip install openai-agents "sideseat[openai-agents]"
    ```
  </TabItem>
  <TabItem label="uv">
    ```bash
    uv add openai-agents "sideseat[openai-agents]"
    ```
  </TabItem>
</Tabs>

Start a local server with `npx sideseat` and set `OPENAI_API_KEY`.

## Quick start

```python
import sideseat
from agents import Agent, Runner, function_tool

sideseat.init(integrations=["openai-agents"])


@function_tool
def get_weather(city: str) -> str:
    """Get the weather for a city."""
    return f"Sunny in {city}, 22°C"


agent = Agent(
    name="Travel assistant",
    instructions="Answer travel questions. Use get_weather for forecasts.",
    model="gpt-6.1-sol",
    tools=[get_weather],
)

with sideseat.session("conversation-42", user_id="user-7"):
    result = Runner.run_sync(agent, "What's the weather in Lisbon?")
    print(result.final_output)
```

`Runner.run` is traced the same way in async code.

## Without the SDK

```bash
pip install openai-agents logfire opentelemetry-exporter-otlp
```

```python
import logfire
from opentelemetry.exporter.otlp.proto.http.trace_exporter import OTLPSpanExporter
from opentelemetry.sdk.trace.export import BatchSpanProcessor


def keep_session_id(match: logfire.ScrubMatch):
    # Logfire redacts attributes whose names mention "session", session.id included.
    return match.value if match.path == ("attributes", "session.id") else None


logfire.configure(
    send_to_logfire=False,
    console=False,
    scrubbing=logfire.ScrubbingOptions(callback=keep_session_id),
    additional_span_processors=[
        BatchSpanProcessor(OTLPSpanExporter(endpoint="http://localhost:5388/otel/default/v1/traces"))
    ],
)
logfire.instrument_openai_agents()
```

## What you see in SideSeat

- One trace per run, with spans for the agent, each handoff, each model call, and each tool call.
- Model, token counts, and cost on every model call.
- The conversation, including tool calls and results, in the Messages tab.

## Known limits

- The Agents SDK also uploads its traces to the OpenAI platform. `agents.set_trace_processors([])`
  removes that upload and keeps SideSeat's spans; `agents.set_tracing_disabled(True)` turns off both.
- Logfire records an attached image as its data URL in text and an attached file by its name only,
  so the Messages tab shows the image's URL rather than the image and does not show the file.
