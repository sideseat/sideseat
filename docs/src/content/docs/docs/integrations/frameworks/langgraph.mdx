[LangGraph](https://docs.langchain.com/oss/python/langgraph/overview) builds stateful agents as graphs.
SideSeat instruments it with the OpenInference LangChain instrumentor, which the `langgraph` extra
installs.

## Install

<Tabs>
  <TabItem label="pip">
    ```bash
    pip install langgraph langchain-aws "sideseat[langgraph]"
    ```
  </TabItem>
  <TabItem label="uv">
    ```bash
    uv add langgraph langchain-aws "sideseat[langgraph]"
    ```
  </TabItem>
</Tabs>

Start a local server with `npx sideseat`. The model runs on Amazon Bedrock, so configure AWS
credentials and a region; any LangChain chat model works the same way.

## Quick start

```python
import sideseat
from langchain_aws import ChatBedrockConverse
from langchain_core.messages import HumanMessage
from langchain_core.tools import tool
from langgraph.graph import START, MessagesState, StateGraph
from langgraph.prebuilt import ToolNode, tools_condition

sideseat.init(integrations=["langgraph"])


@tool
def get_weather(city: str) -> str:
    """Get the weather for a city."""
    return f"Sunny in {city}, 22°C"


model = ChatBedrockConverse(model="global.anthropic.claude-sonnet-5-5").bind_tools([get_weather])


def call_model(state: MessagesState) -> dict:
    return {"messages": [model.invoke(state["messages"])]}


graph = StateGraph(MessagesState)
graph.add_node("model", call_model)
graph.add_node("tools", ToolNode([get_weather]))
graph.add_edge(START, "model")
graph.add_conditional_edges("model", tools_condition)
graph.add_edge("tools", "model")
agent = graph.compile()

with sideseat.session("conversation-42", user_id="user-7"):
    result = agent.invoke({"messages": [HumanMessage("What's the weather in Lisbon?")]})
    print(result["messages"][-1].text)
```

## Without the SDK

```bash
pip install langgraph langchain-aws openinference-instrumentation-langchain opentelemetry-sdk opentelemetry-exporter-otlp
export OTEL_EXPORTER_OTLP_ENDPOINT=http://localhost:5388/otel/default
```

```python
from openinference.instrumentation.langchain import LangChainInstrumentor
from opentelemetry import trace
from opentelemetry.exporter.otlp.proto.http.trace_exporter import OTLPSpanExporter
from opentelemetry.sdk.trace import TracerProvider
from opentelemetry.sdk.trace.export import BatchSpanProcessor

provider = TracerProvider()
provider.add_span_processor(BatchSpanProcessor(OTLPSpanExporter()))
trace.set_tracer_provider(provider)
LangChainInstrumentor().instrument(tracer_provider=provider)
```

To group turns into a session without the SDK, start each turn inside a span that carries `session.id`
and `user.id` attributes.

## What you see in SideSeat

- One trace per graph invocation, with a span for each node.
- A span per model call with the model, token counts, and cost.
- A span per tool call with its arguments and result.
- The conversation, including the tool round trips, in the Messages tab.

## Known limits

- The OpenInference instrumentor refuses LangChain versions newer than the one it was released
  against. The SDK skips that check; without the SDK, pass `skip_dep_check=True` to `instrument` if it
  reports an unsupported version.
