[Strands Agents](https://strandsagents.com) for TypeScript emits OpenTelemetry GenAI spans through the
global tracer provider. The SideSeat TypeScript SDK registers that provider and points it at your project.

## Install

```bash
npm install @strands-agents/sdk @sideseat/sdk zod
```

Node.js 20.19 or newer. Start a local server with `npx sideseat`. The model runs on Amazon Bedrock, so
configure AWS credentials and a region.

## Quick start

```ts
import * as sideseat from "@sideseat/sdk";
import { Agent, tool } from "@strands-agents/sdk";
import { z } from "zod";

await sideseat.init({ integrations: ["strands"] });

const getWeather = tool({
  name: "get_weather",
  description: "Get the weather for a city.",
  inputSchema: z.object({ city: z.string() }),
  callback: ({ city }) => `Sunny in ${city}, 22°C`,
});

const agent = new Agent({
  model: "global.anthropic.claude-sonnet-5-5",
  tools: [getWeather],
});

await sideseat.session({ sessionId: "conversation-42", userId: "user-7" }, async () => {
  await agent.invoke("What's the weather in Lisbon?");
  await agent.invoke("And what should I pack?");
});
```

Run it with `npx tsx agent.ts`. Call `init` before the first agent invocation.

## Without the SDK

```bash
npm install @strands-agents/sdk @opentelemetry/sdk-trace-node @opentelemetry/sdk-trace-base @opentelemetry/exporter-trace-otlp-http
export OTEL_EXPORTER_OTLP_ENDPOINT=http://localhost:5388/otel/default
```

```ts
import { OTLPTraceExporter } from "@opentelemetry/exporter-trace-otlp-http";
import { BatchSpanProcessor } from "@opentelemetry/sdk-trace-base";
import { NodeTracerProvider } from "@opentelemetry/sdk-trace-node";
import { Agent } from "@strands-agents/sdk";

const provider = new NodeTracerProvider({
  spanProcessors: [new BatchSpanProcessor(new OTLPTraceExporter())],
});
provider.register();

const agent = new Agent({ model: "global.anthropic.claude-sonnet-5-5" });
await agent.invoke("What's the weather in Lisbon?");

await provider.shutdown();
```

Plain OpenTelemetry has no session scope; without the SDK, turns are not grouped into a session.

## What you see in SideSeat

- One trace per `invoke`, rooted at the agent span.
- A span per Bedrock call with the model, token counts, and cost.
- A span per tool call with its arguments and result.
- Every turn inside `session()` grouped into one session.
